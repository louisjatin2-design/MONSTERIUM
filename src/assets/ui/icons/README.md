# UI-Button-Icons (Drop-in)

Hier kommen die **Icon-Bilder für die Buttons** hinein (z. B. deine runden
Neon-Embleme). Lege einfach eine Bilddatei mit dem passenden **Slot-Namen** ab –
der Button zeigt dann dein Bild statt des Emojis. Ohne Datei bleibt das Emoji.

- **Format:** `png`, `webp`, `jpg` oder `svg` (PNG mit transparentem Hintergrund
  sieht am besten aus).
- **Größe:** quadratisch, z. B. 256×256. Wird automatisch skaliert.

## Slots → Dateiname

| Button (im Spiel) | Dateiname            | Emoji-Fallback |
|-------------------|----------------------|----------------|
| Kämpfen           | `kaempfen.png`       | ⚔️             |
| Multiplayer       | `multiplayer.png`    | 🌐             |
| Quests / Aufträge | `quests.png`         | 📋             |
| Lager             | `lager.png`          | 📦             |
| Events            | `events.png`         | 🎪             |
| Season Pass       | `pass.png`           | 🎟️             |
| Laden / Shop      | `laden.png`          | 🛒             |
| Monster (oben)    | `monster.png`        | 📖             |

## Vorschlag für deine 6 Bilder

Basierend auf den Symbolen:

| Dein Bild                        | speichern als       |
|----------------------------------|---------------------|
| Gekreuzte Klingen (X)            | `kaempfen.png`      |
| Schriftrolle mit „!"             | `quests.png`        |
| Wappen mit Krone/Stern/Flügeln   | `multiplayer.png`   |
| Kiste / Box                      | `lager.png`         |
| Kamera                           | `events.png` *(oder beliebiger anderer Slot)* |
| (6. Bild)                        | passender Slotname  |

Du kannst jedes Bild frei einem Slot zuordnen – es zählt nur der **Dateiname**.
